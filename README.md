# 一二布布 · 小小大冒险

一二和布布变小了：沙发成了山，书页成了坡道，零食和生活用品构成了可以攀登、绕行和利用的冒险世界。这是一款基于 Three.js 的单人第三人称动作肉鸽网页游戏，采用电脑与手机横屏操作，使用静态文件部署，无需服务器或账号。

本项目是**非商业同人二创**，角色原作者为**黄小B**。当前版本 **1.1.0** 增加了真实高低差路线、角色骨骼步态、手持武器动作、连击和战斗反馈。角色与场景由三维模型组成；准备室插画及材质图集由内置 GPT Image 工具生成。美术来源和制作边界见 [ARTWORK.md](ARTWORK.md) 与 [资源记录](public/art/CREDITS.md)。

## 开始游玩

开局选择一二或布布，本局角色固定。武器自动攻击并辅助瞄准；玩家通过移动、镜头方向、角色技能和环境机关应对敌群。击败敌人后收集经验，在暂停的三选一界面中获得武器或能力。每人最多装备三把武器，最高五级，五级时进化。

一二使用「蹦蹦突进」快速突破包围，初始武器为珍珠奶茶；布布生命较高，使用「抱枕反击」短暂守护后反击，初始武器为平底锅。两名角色都能获得全部武器。

| 场景 | 首领出现时间 | 环境交互 |
| --- | --- | --- |
| 客厅 · 晨光地毯 | 2 分 30 秒 | 风扇吹散追兵、多米诺连锁、零食罐挑战、弹跳机关 |
| 厨房 · 零食王国 | 2 分 45 秒 | 蜂蜜减速、水壶冲击、零食罐挑战、弹跳机关 |
| 庭院 · 午后花园 | 3 分钟 | 喷水器冲击、恢复蘑菇弹床、零食罐挑战、弹跳机关 |

时间从各关开始计算，首领战另计；成长选择与暂停期间不推进游玩计时。普通敌波会逐渐加密，约每 30 秒出现一名精英，首领出现后需将其击败。击败前两关首领后进入「星星补给站」，可花 30 零食币选择一项升级，也可跳过；进入下一关恢复部分生命。击败第三关首领即通关，生命归零则结束本局。

## 高台路线与战斗规则

每关都包含可以实际走通的**坡道 → 高台 → 桥梁 → 下坡**路线，而非仅作为布景。桥下保留通行空间，角色与敌人遵循重力、地面支撑和分层碰撞；高处与低处的身体、近战和弹道需要满足各自的高度及遮挡条件。

- **登高与绕行：** 沿坡道走上高台，可以换路线、跨过敌群或占据更好的射界；高处不能免疫所有攻击，远程敌人和首领仍会制造压力。
- **弹跳与落地：** 互动弹跳机关会施加向上的初速度（12 游戏单位/秒）；腾空时仍可移动。从超过约 1.2 游戏单位的高度落地会触发震波，范围和伤害随跌落高度增长并设有上限，普通小台阶不会触发。
- **桥心星星：** 每关首次到达桥心星星并站稳，可获得 **15 零食币、12 基础经验，以及 20 秒经验拾取翻倍**。翻倍计时只在实际游玩时推进，每关重置，不能重复刷取同一关的星星。
- **高打低：** 从高于目标脚底超过 0.9 游戏单位的位置发出的远程伤害增加 **20%**；近战不获得此项加成。
- **连续击杀：** 每次击杀续接 **3.5 秒**连击窗口，每一连击增加 **1% 伤害，最多 20%**。超过窗口未继续击杀时连击归零。HUD 显示连击剩余时间、高地与腾空状态。

角色身体使用骨骼形变形成连续步态，布布身体与腿脚没有明显横向接缝。武器连接到手部或装备挂点，轮流出手，攻击有前摇、打击与收招。命中反馈包含短暂停顿、受击闪白、漂浮伤害数字、暴击、击退和分层音效。

## 操作

| 功能 | 电脑 | 手机横屏 |
| --- | --- | --- |
| 移动 | WASD 或方向键 | 左侧虚拟摇杆 |
| 转动镜头 | 拖动画面，或 Q / E | 右半屏拖动 |
| 角色技能 | 空格 | 技能按钮 |
| 使用附近机关 | F | 接近时点击交互按钮 |
| 暂停与继续 | Esc 或暂停按钮 | 暂停按钮 |

准备室的「怎么玩」包含操作与高低差提示。竖屏可以选择角色，开始时显示旋转提示并暂停，转为横屏后自动继续。切到后台时自动暂停。设备发热或帧率不足时，可在准备室选择「流畅」画质；声音也可关闭。

## 内容范围

这是具有开局、成长、三关路线、首领、胜负结算和重开流程的小体量版本，内容规模不等同于借鉴的商业游戏。

- 两名可选角色，近景背后跟随镜头、自动攻击与前方辅助选敌。
- 三种主题场景，以及真实高低差路线、弹跳、桥心奖励和生活机关。
- 八把武器：平底锅、珍珠奶茶、回旋拖鞋、泡泡机、闹钟炸弹、拍立得、牵牵围巾、玩具列车，各有五级成长与进化表现。
- 十四种成长能力，覆盖伤害、攻速、范围、生存、连锁、拾取及技能冷却，具有重复选择层数限制。
- 追赶、冲锋、远程、重甲、分裂等敌人行为，定期精英和区域首领。
- 本机最高击败数、静音与画质选项；无需外部音频文件的 Web Audio 音效，具有事件节流和声部上限。

当前没有在线多人、账号、跨设备存档、在线排行榜或付费系统。最高记录保存在当前浏览器本地；清理站点数据会删除记录。

## 本地开发与验证

需要 Node.js 20.19+ 或 22.12+，建议使用当前 LTS。首次运行：

```sh
npm install
npm run dev
```

打开终端打印的 Local 地址。开发服务监听局域网：手机与电脑连接同一网络后，可使用 Network 地址进行真机触屏测试。请通过 HTTP 服务启动，直接双击 `index.html` 无法正确加载模块。

```sh
# 游戏规则、战斗与地形测试
npm test

# 生成静态成品到 dist/
npm run build

# 本地预览生产构建
npm run preview
```

画面需要支持 WebGL 2 的现代浏览器。开发模式使用 `?qa=1` 可显示流程与地形测试控制板，生产构建会移除该分支。

**真实手机尚未完成实机测试。** 浏览器中的横屏尺寸检查、规则测试与生产构建不能代替 iOS/Android 上的触摸手感、性能、发热及兼容性验证。请在目标设备上确认后再对外承诺设备支持范围。

## 部署到 GitHub Pages

项目提供 `.github/workflows/deploy.yml`，推送到仓库 `main` 分支后通过 GitHub Actions 测试、构建并部署 `dist/`。Vite 使用相对资源路径 `base: './'`，适配 `用户名.github.io/仓库名/` 项目站点。

1. 上传项目文件，保留 `package-lock.json` 与 `.github/workflows/deploy.yml`；不要上传 `node_modules/`。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。
3. 推送到 `main`，或在 Actions 页面手动运行部署工作流。
4. 工作流成功后，使用部署任务返回的 Pages 地址打开游戏。

工作流配置与本地构建不代表已经完成公网更新，公开版本以成功部署结果为准。也可将 `dist/` 上传至其他静态托管服务。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `src/main.js` | 游戏循环、战斗、机关、首领、流程和镜头 |
| `src/models.js` | 角色骨骼、动画挂点、敌人与武器模型 |
| `src/model-materials.js` | 生物材质图集与受击材质 |
| `src/world.js` | 三场景、贴图、路线模型与机关动画 |
| `src/terrain.js` | 高度采样、重力、分层碰撞与寻路 |
| `src/combat.js` | 连击、弹道、落地、敌波与武器调度规则 |
| `src/data.js` | 武器、能力、敌人参数与成长规则 |
| `src/input.js` | 键鼠、触屏摇杆和镜头输入 |
| `src/ui.js` / `src/style.css` | 准备室、战斗 HUD、选择与结算 |
| `src/effects.js` / `src/audio.js` | 视觉反馈与合成音效 |
| `public/art/` | 随成品发布的插画、材质图集和生成记录 |
| `assets/characters/` | 人物二创参考、历史生成图及来源说明 |
| `tests/` | 游戏规则、战斗与地形回归测试 |

角色比例以用户选定的一二设计为参考；布布全身、双脚与尾巴使用相同棕色，身体到腿脚连续。历史参考图不全量随网页发布；它们是 AI 二创重建设定，不是官方三视图、官方原始图层或可直接播放的动画包。
